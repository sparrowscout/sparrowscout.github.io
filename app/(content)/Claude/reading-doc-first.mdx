# 밑줄 & 메모 요약

- **에이전트 루프** <br/>
  클로드 코드가 작동하는 방식, 컨텍스트 수집 → 작업 수행 → **결과 검증**, 3단계를 반복.
  //결과 검증까지 루프 안에 들어가는지 몰랐음//<br /> Claude Code는 Claude 주변의 **에이전트 하네스**
  역할 (도구, 컨텍스트 관리, 실행 환경 제공) <br /> 에이전트 루프는 모델과 도구로 구성되어 구동됨

- **모델** <br/>
  Sonnet = 코딩 작업, **Opus = 아키텍처 결정 + 강력한 추론**

- **도구** 가 없으면 Claude는 텍스트로만 응답 → 도구가 있어야 에이전트<br/>
  기능 확장 4가지: skills, MCP, hooks, **subagents** //써보고 싶다 !!//

- **CLAUDE.md** = 매 세션마다 로드되는 컨텍스트 / **자동 메모리** = 학습 내용 자동 저장 (200줄 or 25KB 제한)

- **세션 재개**: `--continue` / `--resume` (권한은 복원 안 됨), `--fork-session`으로 원본 영향 없이 분기

- **Skills**는 요청 시 로드, **Subagents**는 완전히 분리된 컨텍스트 → 긴 세션에서 유리

- **계획 모드**<br/> 복잡한 문제는 `Shift+Tab` 두 번으로 연구와 코딩 분리

- **Claude Cowork**<br/>
  **보안**: prompt injection의 주요 벡터는 웹 콘텐츠. 민감 앱(banking 등) 차단 권장. Claude는 스크린샷을 찍어서 화면을 이해함<br/>
  **Cross-app**: Excel↔PowerPoint 간 데이터가 자동 이동될 수 있음. <br/>모바일에서 접속하면 **폰이 데스크톱의 리모트 컨트롤**이 됨 <br/>**Scheduled tasks**: 컴퓨터가 깨어있고 앱이 열려 있을 때만 실행. 건너뛴 작업은 다시 깨어나면 자동 실행
